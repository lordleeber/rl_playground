RL Playground

一組給完全沒碰過強化學習的軟體工程師的可執行教材。 每個 example 是一支跑得動的小程式，配一章從零解釋它的教學頁； 程式碼與章節在同一個 PR 裡交付，所以章裡的每個數字都是那份程式碼真的跑出來的。

不需要 GPU，不需要事先懂機器學習。看得懂 Python 的 for 迴圈和 numpy 陣列就夠了。

這套教材要走到哪

路線是從一張查表走到一個神經網路。第 1 章用 40 格的表格解一個追逐問題， 把「狀態、動作、獎勵、探索」這幾件事建立起來；接下來每一章拆掉前一章的一個假設—— 目標會不會逃、看不看得到障礙物、狀態多到表格裝不下之後怎麼辦—— 直到表格被神經網路取代為止。

章數還沒有定，因為章是跟著程式碼長出來的。 這個 repo 不是先寫好教材再貼程式碼，而是每做完一個 example 就寫一章， 所以「下一章」永遠等於「下一個做完的 example」。目前有 1 章。

怎麼開始

所有指令都在 repo 根目錄執行（rl_playground/ 這一層），全書一致：

git clone <this-repo> rl_playground
cd rl_playground
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

接著挑一章開始。每一章都是自足的單一 HTML 檔，離線也讀得動， 對應的程式碼在同名資料夾裡。

這份教材的寫法

  • 一個 example ＝ 一個 PR ＝ 一章，程式碼和教材同時交付，不事後補寫。
  • 章裡的終端輸出、數字、圖表全部實跑實測，沒有「應該長這樣」的示意輸出。
  • 凡是宣稱「A 比 B 好」，一定附一段你可以自己貼上去跑的對照實驗。
  • 程式碼節錄允許省略，但留下來的每一行都跟 repo 現碼逐字一致，並標注檔名行號。
  • 「指令 → 輸出」的每一對都由 scripts/check_outputs.py 把指令真的跑起來比對， 連結與圖表契約由 check_book.py 驗；兩支都在 repo 根目錄執行。
  • 教材仍然會過期。檢查器只保證它檢查的那一項，不保證它旁邊那一片。 如果某支程式後來被改過而章節沒跟上，以程式碼為準。
